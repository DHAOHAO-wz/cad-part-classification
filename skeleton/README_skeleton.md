# 代码骨架说明（feature extraction / classification）

本目录是与选题报告《基于几何特征工程与轻量机器学习的 CAD 零件分类》配套的
**代码骨架**，面向真实 CAD 数据接入；函数签名、特征清单与模型选型均与报告
"四、初步方案与可行性"一一对应，标 `TODO` 的位置在接入真实数据集后补全。

## 目录与对应关系

| 文件 | 对应报告章节 | 职责 |
|---|---|---|
| `feature_extraction.py` | 特征工程 | 网格 / B-rep 几何量、包围盒与比例、点云分布与 PCA 特征、局部几何与凸包占比 |
| `classification.py` | 建模与对比、结果交付 | 数据加载、特征矩阵、划分标准化、RF / SVM / k-NN / MLP 基线对比、准确率与 F1 / 混淆矩阵评估 |

## 特征清单（FEATURE_NAMES）

- 网格 / B-rep：面与边数量，平面 / 圆柱 / 球面 / 其他面类型占比，表面积、体积；
- 整体形态：包围盒尺寸与长宽比、各方向占比；
- 点云分布：到中心距离的均值 / 标准差 / 最大值；
- PCA：各向异性、线性度、平面度；
- 局部几何：邻域最小特征值统计、平面占比；
- 凸包：凸包体积占比。

## 与现有可运行原型的区别

上级目录 `data.py / features.py / train.py` 是**合成点云占位原型**，已在课程
环境跑通四基线，用于验证流程；本骨架面向**真实网格 / B-rep 数据**，接入 trimesh、
Open3D 或 PythonOCC 后即可替换占位实现。

## 接入真实数据后的步骤

1. 在 `load_dataset` 中读取公开 CAD / 网格数据集，整理类别标签；
2. 在 `load_mesh / sample_point_cloud / mesh_features` 中补全网格与 B-rep 几何量；
3. 运行 `classification.py`，对比基线指标，补充混淆矩阵、特征重要性与错误样例分析。
